# The Crypt of the Hollow King

A retro first-person grid-based fantasy dungeon crawler inspired by classic PC dungeon adventures.

## Prototype v0.2
- Four-character party
- First-person grid movement
- D20-inspired combat
- Character skills
- Fog-of-war automap
- Keys and locked gates
- Hidden treasure
- Resting and healing
- Multiple monster types
- Mobile and desktop controls

Open index.html locally or deploy the repository to Vercel.
